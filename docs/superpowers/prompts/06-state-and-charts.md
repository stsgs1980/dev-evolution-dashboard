# Промт 06: состояние и графики (фазы 6-7)

```text
ФАЗЫ 6-7: Фильтры, состояние и графические обёртки.

ЧАСТЬ А. Состояние и фильтры.

1. Установи nuqs для состояния в URL.
2. Схема параметров: period (30d, 90d, 1y, all, custom:from..to), repos (массив),
   langs (массив), view (для переключателей на экране).
3. FiltersProvider - контекст с мемоизированным значением; селекторы выносятся
   в отдельные хуки, чтобы не ререндерить весь дашборд при смене одного фильтра.
4. useFilteredSnapshot() - берёт снапшот из статического импорта data/snapshot/latest.json
   (импорт на сервере, передача в клиент через props/RSC) и применяет фильтры.
   Сеть - ноль запросов.
5. FilterBar в Topbar: пресеты периода, мультиселект репозиториев (с поиском),
   мультиселект языков, кнопка сброса, счётчик активных фильтров.
6. Сохранение раскладки виджетов на / в localStorage: порядок, скрытые виджеты.

ПРАВИЛА.
- Ссылка с фильтрами воспроизводима в новой вкладке полностью.
- Пустой результат фильтра - это EmptyState с кнопкой сброса, не пустая сетка.
- Фильтры не меняют формулы метрик, только входной период и подмножество репозиториев.
- Селекторы покрыты юнит-тестами: пустой фильтр, один репозиторий, несуществующий язык.

ЧАСТЬ Б. Графики.

1. Графики распределяются по источникам (спека, раздел 6): line, bar, pie, donut
   и radar берём из бесплатных графиков Untitled UI; Tremor нужен только для area,
   stacked area, scatter, tracker и sparkline. Tremor ставить raw-копией в
   src/shared/components/charts/, если пакет конфликтует с Tailwind v4.
   Gantt технологий пишем сами на CSS-сетке: готового нет ни в free, ни в PRO.
2. Обёртки в src/shared/components/charts/, каждая <= 150 строк:
   ActivityArea, ChurnChart, LanguagesStacked (100% stacked area), TechGantt,
   BreadthDepthScatter, CommitTypeDonut, CraftRadar, RepoSparkline, PeriodTracker,
   DmiProgress.
3. Единая тема графиков: цвета только из chart-1..chart-6 токенов темы Untitled UI,
   сетка и оси - из её же border/text токенов. Свои палитры Tremor переопределяются:
   в src/shared/components/charts/ не должно остаться ни одного hex-литерала.
   Тултип - на React Aria, числа через Intl.NumberFormat("ru-RU").
4. Каждый график обязан поддерживать: загрузку (Skeleton фиксированной высоты),
   пустое состояние, null-данные (пунктирный бейдж "нет данных"), состояние ошибки.
5. Доступность: у каждого графика role="img" + aria-label с кратким описанием тренда,
   плюс скрытая таблица с данными (sr-only) для скринридеров.
6. CLS: фиксированная высота контейнера, никаких ресайзов после монтирования.
7. Динамический импорт графиков на уровне экрана: next/dynamic, ssr: false там, где
   нужна ширина контейнера.
8. Числа: tabular-nums, компактные суффиксы (тыс., млн) через Intl.

ТЕСТЫ.
- Фильтры: 5 кейсов на селекторы.
- Обёртка графика: рендерится с пустыми данными и показывает EmptyState, а не падает.
- aria-label присутствует у каждого экспортируемого графика (проверка перебором).

DoD.
[ ] Смена фильтра не вызывает сетевых запросов, ссылка шарится и воспроизводится.
[ ] 10 обёрток графиков готовы, каждая в четырёх состояниях.
[ ] Ни одного переполнения/обрезки подписей в светлой и тёмной теме.
[ ] Все 8 гейтов зелёные; коммиты feat(state): url-driven filters,
    feat(charts): tremor wrappers and theme, feat(charts): empty and null states.
[ ] Отчёт: скриншот каждого графика в двух темах.
```
