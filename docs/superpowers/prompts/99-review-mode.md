# Промт 99: ревью-режим

Вставляется, когда фаза затянулась, качество поехало или нужно независимое ревью
перед релизом. Меняет роль агента с "делаю" на "проверяю".

```text
РЕЖИМ РЕВЬЮ. Ничего не создавай и не правь, пока я не соглашусь с планом правок.
Сначала только анализ.

Проверь текущее состояние репозитория против спеки и правил шаблона.

АРХИТЕКТУРА.
1. Есть ли сетевые вызовы вне scripts/? (git grep по fetch, axios, octokit в src/)
2. Читает ли какой-либо компонент снапшот напрямую, минуя shared/metrics?
3. Есть ли второй primitive-слой: shadcn, Base UI, Radix, cmdk?
4. Есть ли дубли метрик - одна и та же формула в двух местах?
5. Хардкод путей, магические числа вместо констант, `any`.

ПРАВИЛА ШАБЛОНА.
6. Все файлы <= 250 строк, компоненты <= 200, функции <= 50 (npm run check:file-length).
7. Компоненты с 3+ useState без кастомного хука.
8. Отсутствие JSDoc у экспортируемого публичного API.
9. Стиль: двойные кавычки, точка с запятой, 2 пробела, trailing commas, 120 символов.

ДАННЫЕ И ЧЕСТНОСТЬ.
10. Есть ли место, где null превращён в 0 или в пустой массив?
11. Есть ли метрика без basis/confidence?
12. Есть ли инсайт без evidence?
13. Есть ли на UI оценочное суждение о человеке без пометки "эвристика"?
14. Совпадают ли числа в UI с выводом функции (выборочная сверка 3 штук).

ЛОКАЛЬНЫЕ ЗАГЛУШКИ.
15. TODO, FIXME, mock, fake, stub в src/ и data/ (data/ допустим только в тестах).
16. Закомментированный код.
17. Неиспользуемые зависимости в package.json.

СЕКРЕТЫ.
18. git grep по ghp_, github_pat_, .env - в истории и в рабочем дереве.
19. .env.local в .gitignore.

ГЕЙТЫ.
20. Прогони все 8 гейтов и приведи фактический вывод, не пересказ.

ФОРМАТ ОТВЕТА.
Таблица: | # | находка | файл:строка | severity (blocker / major / minor) | предлагаемая правка |
Затем: три главных риска, план правок по порядку, и вопрос - что делаем первым.
Максимум 15 находок, только значимые. Стилистические придирки - одной строкой в конце.

Не правь ничего до моего "поехали".
```

## Команда для проверки перед релизом

```text
РЕЖИМ РЕВЬЮ + чеклист релиза. Прогони промт 99, затем чеклист из
`docs/superpowers/prompts/08-quality-gates.md` (часть В), выведи оба списка
с фактическими результатами и дай вердикт: готово к v1.0.0 или нет.
```
