# Промт 00: оркестратор

Мета-промт. Вставляется, когда фаз много и нужно, чтобы агент сам держал дисциплину.

```text
Ты ведёшь проект dev-evolution-dashboard по плану
`docs/superpowers/plans/dev-evolution-dashboard.plan.md`.
Спека: `docs/superpowers/specs/dev-evolution-dashboard.spec.md`. Бриф: `BRIEF.md`.

РЕЖИМ РАБОТЫ.

1. В начале каждого ответа выводи строку статуса:
   [INFO] Фаза <N>/11 - <название> - шаг <k>
2. Работай ровно с одной фазой за раз. Не начинай следующую, пока не закрыт DoD текущей.
3. Перед правкой читай файл. После правки не пересказывай код целиком - только суть.
4. Перед каждым коммитом прогоняй гейты:
   npm run lint && npm run typecheck && npm run lint:css && npm run lint:md
   && npm run format:check && npm test && npm run check:file-length && npm run check:docs
   Если гейт красный - чини сам, не спрашивая, если причина техническая.
   Спрашивай, только если нужно продуктовое решение.
5. Соблюдай anti-monolith: 250 строк файл, 200 компонент, 50 функция, 3+ useState -> хук.
   При превышении выводи [ANTI-MONOLITH] Threshold exceeded: <reason> и дроби.
6. Ответы по-русски. Без эмодзи. Теги: [OK], [FAIL], [TODO], [WARNING], [INFO].
7. В конце каждой фазы выдай:
   - что сделано,
   - какие файлы созданы и изменены,
   - какие гейты прошли,
   - какой коммит создан,
   - что нужно от меня перед следующей фазой.

ЗАПРЕТЫ.

- Не менять формулы метрик из спеки без моего явного согласия. Если формула кажется
  неверной - скажи, предложи альтернативу, жди решения.
- Не добавлять новые зависимости без строки обоснования: задача, почему не решается
  существующим стеком.
- Не оставлять TODO, заглушки и моковые данные в UI.
- Не пушить в main без зелёных гейтов.

СТАРТ. Прочитай BRIEF, спеку и план. Ответь: список фаз, текущая фаза, три главных
риска и первый шаг. Кода не пиши, пока я не подтвержу.
```

## Когда использовать

| Ситуация                         | Промт                |
| -------------------------------- | -------------------- |
| Первый заход, надо свериться     | 00 (этот)            |
| Работа над конкретной фазой      | 01-08 по номеру фазы |
| Фаза затянулась, качество плывёт | 99                   |
| Нужен ревью-проход перед релизом | 08 + чеклист из 99   |
