# Промт 07: экраны (фаза 8)

```text
ФАЗА 8: Экраны на реальных данных.

ЦЕЛЬ. Наполнить 8 маршрутов из раздела 5 спеки. Это самая объёмная фаза, поэтому
работай по одному экрану: экран -> гейты -> коммит -> следующий.

ОБЩИЕ ПРАВИЛА.
- Данные только через shared/metrics и shared/models. Прямой импорт снапшота в
  компонент запрещён.
- Структура каждого экрана:
  src/features/<screen>/<screen>.tsx        - композиция, <= 200 строк
  src/features/<screen>/components/*.tsx    - виджеты, <= 150 строк каждый
  src/features/<screen>/hooks/*.ts          - по одному хуку на виджет с useState
- Каждый виджет - SectionCard с подписью источника данных и иконкой-ссылкой
  на /methodology рядом с заголовком метрики.
- Страховка на каждом экране: error boundary + Suspense с Skeleton.
- Адаптация блоков: shadcnblocks (shell, sidebar, KPI), shadcnstudio (карточки
  статистики, таблицы с фильтрами), shadcndeck (секции для /methodology).
  Это ПОРТ, а не копия: переносим структуру и порядок секций, а разметку, классы,
  токены и иконки берём из Untitled UI на React Aria. Готовый код shadcn-блока
  в проект не попадает: он тянет Base UI и свою палитру.
  Компоненты, которые уже есть в Untitled UI (таблица, метрики, тултип, модалка,
  фильтр-бар, page header, sidebar), не переписываем - используем их.
  Готовых страниц-примеров в free-наборе нет: шелл и каждый экран компонуются
  из бесплатных блоков. PRO-компоненты не добавлять (см. docs/ui-components.md).

ЭКРАНЫ ПО ПОРЯДКУ.

1. / (Обзор)
   KPI-строка: коммиты за период, активные дни, медианный размер коммита,
   текущая серия, DMI с дельтой. Далее: карточка текущей эры с описанием,
   ActivityArea, CommitTypeDonut, топ-3 инсайта, топ-5 репозиториев по коммитам.
   Все виджеты реордерабельны (свяжется с фазой 9).

2. /timeline
   Горизонтальный таймлайн эр: цвет полосы = доминирующий язык, высота = относительная
   активность. Точки перелома (adoption-даты инструментов) как маркеры с тултипом.
   Ниже: таблица эр - период, название, коммиты, репозитории, ключевые изменения.
   Drag-скраббер периода появится на фазе 9, оставь слот.

3. /stack
   LanguagesStacked по кварталам; TechGantt по словарю технологий (firstSeen-lastSeen);
   BreadthDepthScatter по годам; таблица "технология, первое появление, репозиториев,
   последнее использование, статус (активна/забыта)".

4. /repos
   Таблица: имя, статус (Active/Dormant/Abandoned), язык, коммиты, последний коммит,
   спарклайн, health, ссылка. Сортировка по всем колонкам, фильтры, поиск.
   Основа - Table из React Aria через Untitled UI: сортировка и клавиатурная
   навигация приходят из primitive, а не пишутся руками.
   Строка раскрывается в краткую сводку. Пагинация или виртуализация при > 50 строк.

5. /repos/[name]
   Заголовок с бейджем статуса и health. Блоки: активность по месяцам, чанж,
   дисциплина коммитов (filesPerCommit распределение), языки внутри репо,
   манифест-история (когда появились ключевые зависимости), последние 20 коммитов.
   404 с понятным сообщением, если репозитория нет в снапшоте.

6. /craft
   CraftRadar (7 флагов практик), adoption-таймлайн инструментов, conventionalRatio
   по кварталам, гистограмма filesPerCommit, giantCommitShare, микши типов коммитов,
   таблица "практика, первое появление, в скольких репозиториях".

7. /insights
   Карточки по severity с раскрытием evidence (числа, период, репозитории).
   Фильтр по severity. Пустое состояние: "Правила не сработали - это тоже сигнал".

8. /methodology
   Для каждой метрики: определение, формула, единица, ограничения, что не измеряется.
   DMI: формула дословно из спеки 4.7, веса, компоненты. Версия снапшота и дата сбора.
   Дисклеймер: "Метрики описывают артефакты в репозиториях, а не человека".
   Оглавление с якорями.

DoD на каждый экран.
[ ] Данные реальные, ни одного TODO и мок-объекта.
[ ] Есть пустое состояние и состояние ошибки.
[ ] Числа на экране совпадают с выводом соответствующей функции (сверка вручную,
    пары "экран - функция" выпиши в отчёт).
[ ] Мобильный вид не ломается (проверка на 375px).
[ ] Файлы в лимитах, 8 гейтов зелёные, коммит feat(<screen>): <name> page.
```
