# Промт 05: дизайн-система и шелл (фаза 5)

```text
ФАЗА 5: Дизайн-система и каркас приложения.

ЦЕЛЬ. Токены, темы, шелл дашборда и базовые примитивы. Никаких данных и графиков,
только конструкция.

ШАГ 1. Токены. База - семантический слой Untitled UI (он уже в теме после CLI init),
расширяем его, а не заменяем своим.
- Проверь, что в теме есть семейства: text, background, foreground, border, brand,
  utility, и что у каждого токена явная пара "светлая / тёмная".
- Добавь от себя только то, чего нет: chart-1..chart-6 для графиков Tremor.
- Свою палитру с нуля не изобретай: две системы токенов в одном проекте конфликтуют.
- Значения в oklch. Светлая тема в :root, тёмная в .dark.
- color-scheme: light dark; переключение темы без вспышки через next-themes.
- Типографика: шкала 12/14/16/20/24/30/38, межстрочные, tabular-nums для чисел.
- Радиусы: 6/8/12/16. Тени: 3 уровня, сдержанные.
- Один акцентный цвет + нейтральная шкала. Не более двух акцентов на экран.
- Контраст: текст на фоне >= 7:1, служебный текст >= 4.5:1. Проверь обе темы.

ШАГ 2. Композиция шелла в src/shared/components/layout/.
- DashboardShell.tsx - сетка: сайдбар 240px, контент, максимум 1440px.
  Компоненты берём из Untitled UI (application shell, sidebar, header), не пишем
  навигацию с нуля.
- Sidebar.tsx - навигация по 8 маршрутам из спеки, `@untitledui/icons`, активный пункт,
  сворачивание до 64px с сохранением в localStorage, адаптив в Sheet на мобильном.
- Topbar.tsx - хлебные крошки, слот фильтров (появится на фазе 6), переключатель темы,
  кнопка Cmd+K.
- CommandPalette.tsx - Dialog из React Aria + внутренний поиск: переходы по экранам,
  переключение темы, быстрые фильтры. Открытие по Cmd+K / Ctrl+K.
  Если Untitled UI не даёт готовую палитру, собираем на React Aria Dialog + listbox,
  без cmdk, чтобы не тянуть вторую систему команд.
- PageHeader.tsx - заголовок, описание, слот действий.

ШАГ 3. Примитивы в src/shared/components/ui/.
Stat (label, value, delta, hint), Badge со статусами репозитория, Table с сортировкой,
Tabs, Tooltip (React Aria), Skeleton, EmptyState (иконка, заголовок, описание,
действие), SectionCard (заголовок, подпись источника, слот действий, контент),
MetricValue (число + единица + tooltip с формулой и ссылкой на /methodology).

ШАГ 4. Заглушки маршрутов.
Создай 8 страниц из раздела 5 спеки, каждая - PageHeader + EmptyState
"Данные появятся на фазе 8". Маршруты должны существовать и быть в навигации.

ПРАВИЛА.
- React Aria - единственный primitive-слой, идёт вместе с Untitled UI. Ad-hoc модалки
  и тултипы не пишем.
- Иконки: `@untitledui/icons` основной слой, stroke 1.5, размеры 16/20/24,
  `aria-hidden` для декоративных. lucide - только добор, не в одном файле с ними.
- Никаких анимаций на этом шаге, кроме переходов hover/focus на CSS.
- Каждый интерактивный элемент: видимый focus-visible, корректный aria-label,
  целевой размер >= 44x44 для тач-целей.
- Файлы <= 250 строк, компоненты <= 200.

ТЕСТЫ (smoke).
- Рендер DashboardShell без падения, сайдбар содержит все 8 пунктов.
- CommandPalette открывается по хоткею и находит маршрут по подстроке.
```
