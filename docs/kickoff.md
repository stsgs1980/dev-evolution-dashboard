# Kickoff: стартовый промт для нового проекта

Первое сообщение в чат AI Assistant после клонирования шаблона. Бриф нового
проекта обсуждается заранее, в любом чате, до создания репозитория; в чат
WebStorm он вставляется руками.

## Как использовать

1. Соберите бриф проекта заранее (состав — в конце файла).
2. Клонируйте шаблон, откройте проект в WebStorm.
3. Скопируйте блок «Промт» целиком, вставьте в чат AI Assistant и замените
   строку с `БРИФ ПРОЕКТА:` на свой бриф.
4. Отправляйте: агент проведёт по Steps 1-5 из
   [getting-started.md](getting-started.md) диалогом. Решения (имя, описание,
   README, стек) принимаете вы.

## Промт

```text
БРИФ ПРОЕКТА: <ваш бриф — см. «Из чего состоит бриф»>

Ты настраиваешь новый проект из шаблона webstorm-config. Порядок работы:

1. Прочитай бриф проекта. Если данных не хватает для старта — задай
   уточняющие вопросы и дождись моего ответа.
2. Изучи правила шаблона: `.aiassistant/rules/AI Rules.md` и
   `docs/getting-started.md`, и соблюдай их во всей работе.
3. Проведи меня по Steps 1-5 из `docs/getting-started.md` строго диалогом:
   на каждом шаге предложи варианты и жди моего выбора. Имя проекта,
   описание, README и стек я выбираю сам; за меня не решай.
4. После каждого шага сделай коммит в формате Conventional Commits.
5. На Step 5 пройди гейты до зелёного: npm run lint, npm run typecheck,
   npm run lint:css, npm run lint:md, npm run format:check, npm test,
   npm run check:file-length, npm run check:docs.
```

## Из чего состоит бриф

- Идея: что за проект и для кого.
- Стек: React из коробки или другой фреймворк (Vue, Svelte, Astro, Next.js).
- Обязательные возможности: что должно быть в первой версии.
- Anti-goals: что проект точно не должен делать.
